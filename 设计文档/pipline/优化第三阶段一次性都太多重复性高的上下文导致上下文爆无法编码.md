```markdown
# game-code-generator

## Goal

将一个完整游戏版本转换成可运行代码。

## Architecture

This skill has TWO stages:

1. Planner
2. Coder

- Vn.md
- GAME_ARCHITECTURE.md
- assets.json
- existing source code

- codegen-contracts/
- dependency graph
- execution waves

2. Understand architecture.
3. Understand all required assets.
4. Identify implementation units.

Each contract:

- target 2~4KB
- maximum 5KB
- one clear implementation responsibility
- explicit dependencies
- explicit file ownership
- explicit asset usage
- explicit acceptance criteria

---

# Stage 2: Coder

Coder receives:

- ONE contract
- allowed dependency files
- codegen-assets.json

Coder MUST:

1. Read assigned contract first.
2. Only read listed dependency files.
3. Only modify owned files.
4. Implement the contract.
5. Run targeted tests.

Coder MUST NOT:

- Read GDD.md
- Read GAME_ARCHITECTURE.md
- Read assets.json
- Read unrelated project files
- Redesign architecture
- Implement features outside the contract

If contract is insufficient:

STOP and report missing information.

Do not explore the entire repository.

---

# Asset Rules

Coder uses:

codegen-assets.json

Coder should use:

assets/final/

Coder should never use:

assets/raw/

After all contracts in a wave complete:

1. Run tests.
2. Run TypeScript checks.
3. Run build.
4. Run integration tests.

Only then start the next wave.

- build passes
- game launches

- completion condition works
```

# 三十九、关于你现在的 `7 Read / 0 Write`

我认为这个现象**不应该继续靠“换更大的模型/增加 session 时间”解决**。

因为根本问题不是：

```text

Task Context
```

你当前实际上把：

```text
     ↓
```
